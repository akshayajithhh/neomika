# Neomika's 1st Birthday Celebration Invitation 🌸

A responsive, luxury birthday invitation website designed for baby girl **Neomika's 1st Birthday Celebration** on **22nd August 2026** at **Blanco Convention Centre, Kannanchery, Kozhikode**.

## ✨ Features
- **Centerpiece Invitation Showcase**: Tap-to-enlarge high-resolution invitation card with 1-touch save to photos.
- **Scroll Reveal Animations**: Smooth entry transitions with top reading progress indicator.
- **Live Countdown Timer**: Dynamic ticker calculating days, hours, minutes, and seconds until the celebration.
- **1-Click Calendar Sync**: Add event to Google Calendar or download `.ics` for Apple / Outlook Calendar.
- **Venue Directions**: 1-click Google Maps navigation for Blanco Convention Centre, Kannanchery.
- **WhatsApp Wishes Integration**: Direct birthday blessings sent to `+91 96459 38443` with celebratory confetti.
- **Ambient Vintage Music Box**: Web Audio API synthesized lullaby melody.

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
